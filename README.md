# translate2code

**适合希望对 AI 生成内容做简单把控的人。**

translate2code 是一个面向 Python 开发的 Codex 技能。它让 AI 先用自然语言说明准备做什么、会改哪些位置，等你确认后再写代码；每完成一个模块，就提交修改和测试结果，等你检查后继续。

你可以围绕三件事参与审阅：**要做什么、允许改哪里、结果是否符合预期。** 发现方向不对时，可以先调整设计，再让 AI 实现。

## 它如何帮助你把控生成过程

- **先看设计**：实现前列出目标、输入输出、文件位置和修改范围。
- **确认后动手**：你回复“允许进行”，AI 才开始实现已批准的模块。
- **每次检查一部分**：按模块依次实现、测试，提交结果供你验收。
- **把问题留在当前步骤解决**：设计不清楚、测试失败或改动超出范围时，先报告和处理，再继续。

主 agent 负责设计与审查，子 agent 按批准的设计实现。你在设计确认和结果验收两个节点决定是否继续。

## 安装

在 Codex 中输入：

```text
$skill-installer 从 https://github.com/LovelyBear2004/translate2code 安装仓库根目录的技能，命名为 translate-to-code。
```

也可以手动克隆到个人技能目录：

```bash
mkdir -p ~/.agents/skills
git clone https://github.com/LovelyBear2004/translate2code.git ~/.agents/skills/translate-to-code
```

安装后使用 `$translate-to-code` 调用。若下一轮对话中未出现技能，重启 Codex。目标目录已经存在时，先确认已有内容。

## 示例：写一个斐波那契兔子程序

### 1. 提出需求

在你的项目中向 Codex 输入：

```text
$translate-to-code 写一个计算斐波那契兔子序列的 Python 程序。
输入月份，输出每个月的兔子对数。
```

### 2. 先检查 AI 的设计

AI 会先阅读项目并提出设计，例如：

```text
M-001：兔子序列计算与命令行输出

计划新增：rabbits.py 和相关测试文件。
输入：正整数月份 n。
输出：第 1 至第 n 个月的兔子对数。
计算规则：前两个月各 1 对，之后每个月等于前两个月之和。
验收方式：第 10 个月应为 55 对；非法输入应给出错误提示。
```

此时先检查这些规则是否符合你的想法。比如，你希望输出的是“兔子只数”，就可以要求它先修改设计，明确一对兔子按两只计算。

设计符合预期后，回复：

```text
允许进行
```

### 3. 查看实现与测试结果

主 agent 会委派子 agent 实现当前模块，运行相关测试，再向你说明生成了哪些文件、怎样运行、测试是否通过。

按最初“输出兔子对数”的设计，生成的程序可以这样运行：

```bash
python3 rabbits.py 10
```

预期输出：

```text
第 1 个月：1 对兔子
第 2 个月：1 对兔子
第 3 个月：2 对兔子
第 4 个月：3 对兔子
第 5 个月：5 对兔子
第 6 个月：8 对兔子
第 7 个月：13 对兔子
第 8 个月：21 对兔子
第 9 个月：34 对兔子
第 10 个月：55 对兔子
```

示例中的 `rabbits.py` 和测试文件由 Codex 在你的项目中生成。

### 4. 验收，或提出修改

检查结果符合需求后，回复：

```text
OK
```

当前模块会被标记为“已验收”。如果结果需要调整，直接说明问题，AI 会在批准范围内修正；涉及设计或范围变化时，先更新设计并确认变化部分。

多个模块的任务按顺序进行。“允许进行”默认批准当前模块，“OK”默认验收当前模块；你也可以明确批准多个模块，已有批准会继续有效。

## 使用条件

- 当前技能用于新增或修改 Python 代码；仅解释代码、审查代码或修改文档时不自动使用。
- 需要支持本地技能及子 agent 委派的 Codex 环境。子 agent 不可用时，会暂停实现，等待你明确允许主 agent 代为实现。
- 执行程序和测试，需要目标项目相应的运行环境。技能本身无需安装 Python 第三方包。
- 技能使用中文编写，实际工作使用用户所使用的语言。

## 如何识别进度

AI 会在设计文档或 Python 注释中记录模块编号和状态：

| 标记示例 | 状态 |
| --- | --- |
| `## [M-001] 待批准` | 设计完成，等你确认 |
| `##** [M-001] 已批准` | 当前允许实现 |
| `###*** [M-001] 待验收` | 实现和相关检查通过，等你检查 |
| `# [M-001] 已验收` | 你已确认结果 |

完整工作流程见 [SKILL.md](SKILL.md)。
